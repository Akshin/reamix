# reamix

Сведение музыки в REAPER вместе с Claude Code. Claude читает проект, вешает плагины, крутит
параметры, рисует автоматизацию и «слышит» результат через рендер и анализ. Слушаешь и
решаешь ты: каждая правка — один шаг undo.

Только macOS. Проверено на REAPER 7.

## Что нужно

- REAPER 7 или новее
- [Claude Code](https://claude.com/claude-code)
- [uv](https://docs.astral.sh/uv/) — запускает инструмент и сам ставит ему Python и библиотеки
- git — чтобы скачать репозиторий (macOS предложит установить его при первом вызове)
- ffmpeg — только для сравнения с референсом

Python отдельно ставить не надо. Homebrew не обязателен, но с ним проще:

```bash
brew install uv ffmpeg
```

Без Homebrew uv ставится так:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

## Установка

Проще всего попросить Claude Code. Открой его в любой папке и напиши:

> Установи reamix из https://github.com/Akshin/reamix — действуй по INSTALL.md в репозитории.

Claude скачает репозиторий, поставит недостающее, скажет, что меняет на машине, и попросит
перезапустить REAPER.

Вручную то же самое делается двумя командами:

```bash
git clone https://github.com/Akshin/reamix.git ~/reamix
~/reamix/install.sh
```

Первый запуск скачивает Python и библиотеки анализа (около 125 МБ на диске) — нужен интернет.

Установка делает четыре вещи:

- дописывает в `REAPER/Scripts/__startup.lua` строку автозапуска моста;
- подключает скиллы `reamix` и `ableton-to-reaper` в `~/.claude/skills/`;
- кладёт ссылку на команду `reamix` в папку из PATH;
- собирает каталог твоих плагинов в `~/.reamix/`.

Перезапусти REAPER и проверь:

```bash
reamix doctor
```

Удаление — `reamix uninstall`. Твои данные в `~/.reamix/` и папки `.reamix` в треках остаются.

## Как пользоваться

1. Положи мультитрек — файлы дорожек, можно по подпапкам — в отдельную папку. Если рядом
   лежит проект Ableton (`.als`), темп, размер и части песни возьмутся из него.
2. Открой Claude Code в этой папке и напиши: «собери проект». REAPER можно не открывать —
   он запустится сам; если он открыт с другим проектом, открой в нём пустую вкладку.
3. Claude осмотрит файлы, спросит темп, если его неоткуда взять, предложит раскладку по
   папкам (барабаны, бас, гитары, вокал…) и после твоего согласия соберёт проект в `reaper/`.
4. Дальше трек идёт по этапам: замысел → монтаж → тембр и динамика → пространство →
   автоматизация → проверка и премастер с запасом под мастеринг. Перед каждым этапом Claude
   задаёт 3–5 вопросов — по одному, с вариантами ответа, — а в конце говорит, что сделал и
   что слушать. Вне очереди тоже можно просить что угодно: «вокал тонет в припеве»,
   «низ мутный».

Проект REAPER уже есть? Открой его в REAPER, а Claude Code — в папке проекта, и начинай с шага 4.

Claude сам вызывает команды `reamix`. Правку он применяет сразу и говорит, что слушать;
ты отвечаешь «оставить» или «откатить». Сравнить на слух можно и самому: Cmd+Z и Cmd+Shift+Z.

В первой сессии Claude заведёт в папке трека `CLAUDE.md` и `docs/` — туда записывается
замысел микса, принятые и отвергнутые решения. Без этого в новом чате он не помнит прошлого.

## Что умеет

| Команда | Что делает |
|---|---|
| `reamix multitrack [--build]` | осмотреть папку с мультитреком и собрать из неё проект для сведения |
| `reamix state` | устройство проекта: треки, уровни, плагины, посылы, огибающие, регионы |
| `reamix fx <трек> [плагин]` | цепочка плагинов; параметры, которые отличаются от умолчания |
| `reamix do "<описание>" '<lua>'` | правка одним undo-блоком, с откатом при ошибке и снимками до и после |
| `reamix ab [before\|after]` | переключить последнюю правку: до / после, с запуском участка по кругу |
| `reamix undo` | откатить последнюю правку |
| `reamix analyze` | рендер микса и стемов: громкость, пики, спектр, стерео, маскирование — с отметками времени |
| `reamix ride <трек> [--vs-mix]` | выровнять громкость трека автоматизацией — саму по себе или относительно микса |
| `reamix phase <трек> <трек>` | проверить фазу между дорожками одного источника |
| `reamix trim [треки]` | гейн-стейджинг: трим первым плагином приводит дорожку к рабочему уровню плагинов |
| `reamix gain <трек>` | уровень дорожки после каждого плагина: кто увёл громкость |
| `reamix reference <файл>` | сравнить микс с референсом |
| `reamix changes` | что изменилось с прошлого раза |
| `reamix plugins find <слова>` | поиск по каталогу установленных плагинов |
| `reamix import-als <файл.als>` | перенести проект Ableton Live в проект REAPER |

Полный список — `reamix --help`; справка для Claude — [skill/SKILL.md](skill/SKILL.md).

## Проект из Ableton

Открой в REAPER пустую вкладку, а Claude Code — в папке проекта Ableton, и напиши:
«перенеси этот проект в REAPER». Claude запустит `reamix import-als`, и рядом с `.als`
появится папка `reaper/` с проектом: дорожки, группы, клипы с варпом, MIDI, плагины с их
настройками, автоматизация. Сэмплы не копируются — оба проекта читают одни файлы.

Не переносятся родные устройства Ableton (Echo, EQ Eight, Simpler и прочие): их в REAPER
нет. Дорожку с ними можно заморозить в Ableton — тогда конвертер возьмёт её звук. Что
перенеслось точно, что приблизительно и что потерялось, Claude расскажет по отчёту.
Подробности — [docs/features/ableton-import.md](docs/features/ableton-import.md).

## Что где лежит

| Место | Что там |
|---|---|
| `<папка трека>/reaper/` | проект REAPER, собранный из мультитрека |
| `<папка трека>/references/` | референсные треки — клади сюда, Claude сравнит микс с ними |
| `.reamix/` рядом с проектом | снимки состояния, журнал правок, рендеры, отчёты анализа |
| `<папка трека>/CLAUDE.md`, `docs/` | память о треке для Claude |
| `~/.reamix/` | каталог твоих плагинов и твои предпочтения |

Снимок хранит полное состояние каждого трека в родном формате REAPER: любой трек можно
вернуть в прежнее состояние, даже когда undo уже недоступен. Рендеры занимают около 23 МБ
на минуту на стем; хранятся два последних набора.

## Что стоит знать

- Claude не слышит звук. Он видит цифры анализа и то, что ты ему говоришь.
- Мост выполняет в REAPER код, который присылает Claude. Он слушает только файлы в папке
  `.ipc` репозитория, сети не касается.
- Команды работают с проектом, открытым в активной вкладке REAPER, и отказываются, если он
  лежит не в той папке, где открыт Claude Code.
- Пока включено состояние «до» (`reamix ab`), ничего не меняй руками: новая запись в
  истории undo сотрёт правку, которую ты сравниваешь.

Как это устроено — [docs/architecture.md](docs/architecture.md).

## Разработка

```bash
uv run pytest
```

Мост и функции над проектом — `bridge/*.lua`, командная строка — `src/reamix/`. Тесты гоняют
мост против подделки API REAPER (`tests/fake_reaper.lua`); настоящее поведение REAPER
проверяется только вживую.
