# Перенос проекта Ableton в REAPER

Команда `reamix import-als` читает файл `.als` и собирает рядом проект REAPER:
`<папка проекта Ableton>/reaper/<имя>.rpp`. Аудио общее — оба проекта смотрят в одну папку
`Samples/`, сэмплы не копируются. Перенос односторонний: это снимок `.als` на момент
запуска, дальнейшие правки в Ableton в REAPER не попадут.

Если человеку нужно только свести трек, этот перенос не нужен: проще и точнее экспортировать
из Ableton дорожки файлами (мультитрек) и собрать проект по скиллу `reamix` — раздел «Новый
трек из мультитрека». Перенос `.als` — когда в REAPER нужны живые плагины, клипы и MIDI.

Звук ты не слышишь. Твоя часть — запустить перенос, честно пересказать, что легло точно, а
что нет, и помочь закрыть пробелы.

## Порядок

1. **Найди `.als`.** Путь из сообщения пользователя; если его нет — `ls *.als` в текущей
   папке. Папку `Backup/` не трогай. Файлов несколько — спроси, какой.
2. **Проверь REAPER:** `reamix status`. «Мост не запущен» — попроси открыть REAPER. Команды
   `reamix` нет — инструмент не установлен: его ставит `reamix install` из репозитория reamix.
3. **Подготовь пользователя** одним сообщением, до запуска:
   - в REAPER должна быть активна **пустая вкладка**: File → New project tab (окно Project
     Settings, если появится, закрыть). В ней соберутся плагины и откроется готовый проект;
   - открытые проекты REAPER должны быть **сохранены**: плагины грузятся в этом же REAPER, и
     если один из них упадёт, несохранённое пропадёт;
   - большой проект грузится минуты: REAPER в это время не отвечает — это нормально. Если
     он покажет окно какого-нибудь плагина (лицензия, предупреждение) — окно надо закрыть,
     перенос пойдёт дальше.
4. **Запусти:** `reamix import-als "<файл.als>"`. Таймаут команды ставь с запасом (10 минут).
   Отказы команда объясняет сама — передай причину пользователю и повтори после исправления:

   | Отказ | Что делать |
   |---|---|
   | «нужна пустая вкладка» | пользователь открывает вкладку, ты повторяешь |
   | «есть несохранённые изменения» | пользователь сохраняет; `--unsaved-ok` — только если он сам так решил |
   | «проект уже есть» | в `reaper/` лежит прошлый перенос, возможно с начатым миксом: спроси. `--force` перезапишет, `--out <папка>` положит рядом |
   | «перенос плагинов прерван на дорожке …» | REAPER не ответил: упал на плагине из списка или ждёт на его окне. Проект с дорожками, клипами и уже собранными плагинами записан. Назови плагины, попроси посмотреть на REAPER, предложи повторить с `--force`; не помогает — `--no-plugins` |

5. **Перескажи итог** своими словами, коротко: сколько дорожек, клипов и плагинов легло;
   затем то, что из блока «не перенесено или требует внимания» влияет на звук. Пути и
   длинные списки не цитируй. Что значат строки — в разделе ниже.
6. **Проект уже открыт в REAPER** (в той пустой вкладке) и сохранён. Попроси пользователя
   включить воспроизведение и сравнить с Ableton на слух.
7. **Дальше — сведение.** Перейди в папку `reaper/` и работай по скиллу `reamix`: там
   `reamix init` заведёт документацию трека, `reamix state` покажет проект.

## Ключи

| Ключ | Когда |
|---|---|
| `--out <папка>` | положить проект не в `reaper/` рядом с `.als` |
| `--force` | перезаписать существующий `.rpp` (только с согласия пользователя) |
| `--copy-media` | скопировать в проект файлы, лежащие вне папки проекта Ableton (Downloads, Splice): иначе ссылки на них полным путём, и проект сломается, когда файлы уберут |
| `--ignore-freeze` | у замороженных дорожек взять исходные клипы и живые плагины, а не звук заморозки |
| `--no-plugins` | только дорожки, клипы и автоматизация микшера; REAPER не нужен |
| `--no-open` | не открывать готовый проект в REAPER |
| `--unsaved-ok` | не останавливаться из-за несохранённых проектов в REAPER |

## Что переносится

| Точно | Приблизительно | Не переносится |
|---|---|---|
| дорожки, группы → папки, возвраты и посылы | варп: те же маркеры, но растягивает другой алгоритм (élastique Pro) | родные устройства Ableton и их автоматизация |
| громкость, панорама, mute, цвета, имена | кривые автоматизации — короткими прямыми | стойки с параллельными цепочками (плагины ставятся выключенными) |
| VST3, VST2 и AU с их настройками | плавное изменение темпа — мелкими ступенями | клипы Session view, дорожки дублей (take lanes) |
| автоматизация микшера и параметров плагинов | закон панорамы (как в Ableton: +3 дБ на краях) | ARA-плагины (Melodyne, VocAlign, Vovious) |
| | | огибающие громкости и питча внутри аудиоклипов |
| клипы, фейды, усиление клипа, транспонирование | | смена размера внутри трека, задержка дорожки |
| MIDI: ноты, педаль и другие контроллеры, pitch bend | | |
| темп и его автоматизация, маркеры | | выходы на внешние каналы звуковой карты |
| сайдчейн (посылом на каналы 3/4) | | |

## Как читать итог и что с этим делать

Полные данные — в `reaper/.reamix/import/<имя>/`: `report.json` (всё по дорожкам),
`native.json` (параметры родных устройств), `plan.json` (какие плагины куда ставились).
В контекст их целиком не тяни: бери нужную дорожку через `jq` или `grep`.

- **«родные устройства Ableton (N)»** — Echo, EQ Eight, Glue Compressor, Utility, Simpler и
  прочие в REAPER не существуют. Варианты, от точного к простому:
  1. *Заморозить дорожку в Ableton* (Freeze Track), сохранить и повторить перенос: конвертер
     возьмёт звук заморозки — он уже со всеми устройствами. Плагины дорожки встанут
     выключенными. Для инструментов (Simpler, Drum Rack, Operator) это единственный точный путь.
  2. *Собрать замену в REAPER.* Параметры устройства есть в `native.json`
     (`jq '.[] | select(.track == "5 Vocal")' native.json`): у EQ Eight — полосы
     `Bands.N/ParameterA/{IsOn,Mode,Freq,Gain,Q}`, у Utility — `Gain`, `StereoWidth`, у
     компрессоров — порог, отношение, атака, восстановление. Замену ставь через `reamix do`
     плагином, который пользователь предпочитает (`reamix prefs`, `reamix plugins find`),
     по одной дорожке за раз, и проси послушать. Utility проще заменить громкостью,
     панорамой и шириной самой дорожки: `rx.track_set`.
  3. *Оставить как есть*, если устройство было выключено или не влияет на звук.
  Поле `automated` в `native.json` — параметры, у которых была автоматизация: она потеряна.
- **«плагинов нет в REAPER»** — REAPER не видит плагин в том формате, что стоял в Ableton,
  и ни в каком другом. Если плагин установлен: REAPER → Settings → Plug-ins → VST →
  Re-scan, затем `reamix plugins scan` и повтор переноса. Если не установлен — назови его.
- **«ARA-плагины не поставлены»** — Melodyne, VocAlign, Vovious и подобные в REAPER
  работают через ARA: правки, сделанные в Ableton, они не подхватят. Точный путь —
  заморозить дорожку в Ableton и повторить перенос; иначе пользователь ставит плагин в
  REAPER сам и делает правки заново.
- **«плагин есть только в другом формате»** — в Ableton стоял, например, VST3, а REAPER
  видит только AU. Настройки между форматами не переносятся: плагин поставлен на своё место
  выключенным, с настройками по умолчанию.
- **«плагин не принял настройки» / «REAPER не смог добавить»** — редкий случай; назови
  плагины, их придётся настроить вручную.
- **«стойки с параллельными цепочками»** — Audio Effect Rack с несколькими цепочками в
  цепочку REAPER не раскладывается. Плагины стоят выключенными; предложи собрать параллель
  вручную (посыл на отдельную дорожку) и включить.
- **«MIDI-дорожки без инструмента»** — инструмент был родным устройством Ableton или
  плагином, которого нет. Ноты на месте, звука нет: заморозка в Ableton либо другой инструмент.
- **«замороженные дорожки»** — взят звук заморозки, исходные клипы и MIDI не перенесены,
  плагины выключены. Нужны живые плагины — повтор с `--ignore-freeze`.
- **«сайдчейн … на каналах 3/4»** — роутинг сделан; попроси пользователя проверить, что в
  самом плагине включён внешний вход.
- **«файлов не найдено»** — клипы этих файлов пропущены. В Ableton: File → Manage Files →
  найти недостающее, затем Collect All and Save, и повторить перенос.
- **«вне папки проекта»** — файлы из Downloads, Splice и т. п. Надёжнее всего
  Collect All and Save в Ableton до переноса; либо повтор с `--copy-media`.
- **«темповая карта REAPER расходится»** — не должно появляться; если появилось, позиции
  после смен темпа неверны: сообщи пользователю и не продолжай сведение.

## Чего ждать от звука

Одинаково зазвучит не всё. Причины расхождений, от частых к редким: родные устройства
Ableton (их нет), варп (другой алгоритм растяжения — заметнее всего на ударных в режиме
Beats), плагины с собственным случайным поведением. Проверить объективно можно так: попроси
пользователя экспортировать микс из Ableton в файл, затем в папке `reaper/` выполни
`reamix analyze` и `reamix reference <экспорт.wav>` — сравнение покажет разницу по
громкости, пикам и балансу полос. Расхождение в отдельной полосе обычно указывает на
дорожку с потерянным устройством.

## Чего не делать

- Не запускай повтор с `--force`, если пользователь уже работал в проекте REAPER: перенос
  затрёт микс. Спроси и предложи `--out`.
- Не обходи отказ про несохранённые проекты молча.
- Не правь `.als` и ничего не меняй в папке проекта Ableton, кроме папки `reaper/`.
