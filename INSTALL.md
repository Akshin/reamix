# Установка reamix — инструкция для Claude Code

Этот файл читает Claude, когда человек просит установить reamix. Действуй по шагам и
говори человеку, что делаешь: установка меняет его машину в четырёх местах.

## Что изменится на машине

Скажи это человеку до начала:

- в `~/Library/Application Support/REAPER/Scripts/__startup.lua` добавится строка автозапуска моста;
- в `~/.claude/skills/` появятся ссылки на скиллы `reamix` и `ableton-to-reaper`;
- в папке из PATH появится ссылка на команду `reamix`;
- в `~/.reamix/` соберётся каталог его плагинов.

Если нет uv, поставится и он; при первом запуске uv скачает Python и библиотеки (около 125 МБ).

## Шаги

1. **Проверь условия.** Нужны macOS (`uname` → `Darwin`) и REAPER, запущенный хотя бы раз:
   должна существовать папка `~/Library/Application Support/REAPER`. Нет REAPER — остановись
   и скажи человеку поставить его; сам не ставь.

2. **Скачай репозиторий** в `~/reamix`:

   ```bash
   git clone https://github.com/Akshin/reamix.git ~/reamix
   ```

   Папка уже есть — обнови: `git -C ~/reamix pull`. Нет git — macOS предложит поставить
   Command Line Tools; попроси человека согласиться и повтори.

3. **Запусти установку:**

   ```bash
   ~/reamix/install.sh
   ```

   Скрипт поставит uv, если его нет (через Homebrew, а без него — установщиком с astral.sh),
   и выполнит `reamix install`. Повторный запуск безопасен.

4. **ffmpeg — по желанию.** Нужен только для сравнения микса с референсом. Если его нет
   (`command -v ffmpeg`), спроси, ставить ли; с Homebrew это `brew install ffmpeg`.

5. **Попроси перезапустить REAPER.** Мост стартует вместе с ним. Сам REAPER не закрывай:
   там может быть несохранённая работа.

6. **Проверь:**

   ```bash
   reamix doctor
   ```

   Все строки должны быть «ок». Команда `reamix` не находится — открой новый терминал
   (PATH обновился) или вызывай `~/reamix/bin/reamix`.

7. **Расскажи, как пользоваться:** положить мультитрек в отдельную папку, открыть Claude Code
   в этой папке и попросить собрать проект (REAPER запустится сам); дальше говорить,
   что не так в миксе. Скилл `reamix` появится в новых сессиях Claude Code, в текущей его ещё нет.

## Если что-то не так

| Что говорит `reamix doctor` | Что делать |
|---|---|
| мост не запущен | REAPER не перезапущен после установки, либо в нём всплыло окно с текстом `reamix: …` — это ошибка запуска, покажи её |
| папка REAPER не найдена | REAPER стоит в нестандартном месте: задать `REAPER_RESOURCE_PATH` и повторить установку |
| каталога плагинов нет | `reamix plugins scan` |
| команды нет в PATH | вызывать `~/reamix/bin/reamix` или добавить `~/.local/bin` в PATH |

## Обновление и удаление

- Обновить: `git -C ~/reamix pull`, затем `reamix reload` (или перезапуск REAPER).
- Удалить: `reamix uninstall`, затем можно стереть `~/reamix`. Данные в `~/.reamix/` и папки
  `.reamix` в треках остаются — их человек удаляет сам, если хочет.
