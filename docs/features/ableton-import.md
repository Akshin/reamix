# Перенос проекта из Ableton Live

`reamix import-als <файл.als>` собирает проект REAPER из проекта Ableton: дорожки, группы,
клипы, плагины с настройками, автоматизация. Для Claude — скилл `ableton-to-reaper`
(`skill-ableton/SKILL.md`).

## Как это устроено

```
.als (gzip с XML) ──▶ ableton.py: модель ──▶ importer.py: пересчёт ──▶ rpp.py: текст .rpp
                                                   │                        ▲
                                                   ▼                        │
                              bridge/import.lua в пустой вкладке REAPER: цепочки плагинов
```

1. **Разбор** (`src/reamix/ableton.py`). Файл читается целиком: в нём всё, что Ableton
   сохраняет о проекте, включая состояние каждого плагина. Скрипт внутри Ableton дал бы
   меньше: состояние плагинов и автоматизацию аранжировки его API не отдаёт.
2. **Пересчёт** (`src/reamix/importer.py`). Доли → секунды по темповой карте, клипы → айтемы,
   автоматизация → точки огибающих, посылы и сайдчейн → приёмы на дорожках.
3. **Плагины** (`bridge/import.lua`). Блок плагина в `.rpp` — заголовок с раскладкой входов
   плюс состояние; заголовок знает только REAPER. Поэтому цепочка каждой дорожки собирается
   в живом REAPER на временном треке, а её блок `<FXCHAIN` забирается текстом.
4. **Запись** (`src/reamix/rpp.py`). Проект пишется одним файлом и открывается на месте
   верстака; REAPER сразу сохраняет его в своём полном виде.

Проект кладётся в `<папка проекта Ableton>/reaper/<имя>.rpp`. Сэмплы не копируются: пути к
ним относительные (`../Samples/...`), оба проекта читают одни файлы. Служебные данные
импорта — в `reaper/.reamix/import/<имя>/`: `report.json`, `native.json` (параметры родных
устройств), `plan.json`, состояния плагинов, точки огибающих, блоки цепочек.

## Верстак

Плагины грузятся в REAPER пользователя, поэтому:

- нужна **пустая активная вкладка** — в ней создаются временные треки и в ней же потом
  открывается готовый проект. Вкладку открывает человек: действие «New project tab»
  показывает модальное окно свойств проекта, и мост на нём встаёт;
- импорт не начинается, если в любой вкладке есть **несохранённые изменения**: упавший
  плагин уносит весь REAPER (`--unsaved-ok` снимает запрет);
- вкладка помечается меткой (`SetProjExtState`), каждый запрос сверяет её: если человек
  переключил вкладку, плагины не встанут в чужой проект;
- экземпляры плагинов **живут до конца импорта**. Создать и удалить плагин за один вызов
  нельзя: Hammer Mk2 (Kush Audio) в таком случае роняет REAPER отложенным обработчиком,
  который срабатывает уже после удаления.

## Соответствие

| Ableton | REAPER | Точность |
|---|---|---|
| группа | папка (`ISBUS`) | точно |
| возврат и посыл | дорожка и приём `AUXRECV`; «pre» у возврата → режим 3 | точно |
| громкость, панорама, выключатель дорожки | `VOLPAN`, `MUTESOLO` | точно |
| закон панорамы (0 дБ в центре, +3 дБ на краях) | −3 дБ с компенсацией, синусная кривая (`VOLPAN … 1.414`) | по документации Ableton |
| цвет дорожки | `PEAKCOL` по палитре Live 10–12 | точно |
| выход на другую дорожку | приём на ней, выход в мастер отключён | точно |
| сайдчейн плагина | приём на каналы 3/4, дорожка в 4 канала | роутинг точно; вход в плагине включает его состояние |
| клип без варпа | айтем: позиция, длина, смещение в файле | точно |
| клип с варпом | скорость воспроизведения; при смене темпа или внутренних варп-маркерах — stretch-маркеры | позиции точно, звук — другой алгоритм |
| зацикленный клип | по айтему на каждый проход цикла | точно |
| усиление, транспонирование, фейды, выключение клипа | громкость и питч тейка, фейды, mute айтема | точно; форма фейда — стандартная |
| MIDI-клип | MIDI-айтем: ноты, сила, выключенные ноты | точно |
| огибающие контроллеров в MIDI-клипе (педаль, модуляция, pitch bend, давление) | сообщения MIDI в айтеме | плавные участки — до 32 сообщений на долю |
| темп и его автоматизация | `TEMPO` и точки `TEMPOENVEX` | плавные участки — ступенями |
| маркеры (локаторы) | `MARKER` | точно |
| автоматизация громкости, панорамы, выключателя, посылов | `VOLENV2`, `PANENV2` (знак перевёрнут), `MUTEENV`, `AUXVOLENV` | кривые — восемью отрезками |
| плагин VST3, VST2, AU | тот же плагин с тем же состоянием | точно |
| автоматизация параметра плагина, выключателя плагина | огибающая параметра, огибающая bypass | точно; параметр ищется по имени |
| замороженная дорожка | звук заморозки, плагины выключены | как в Ableton |
| стойка с одной цепочкой | плагины подряд | громкость цепочки не переносится |

Не переносится: родные устройства Ableton и их автоматизация (параметры — в `native.json`),
стойки с параллельными цепочками (плагины ставятся выключенными), ARA-плагины, клипы Session
view и дорожек дублей, огибающие внутри аудиоклипов (модуляция громкости и питча), смена
размера внутри трека, задержка дорожки, выходы на внешние каналы, раздельная панорама
каналов, кроссфейдер.

## Формат Ableton: что важно знать

- Время в аранжировке — в долях (четвертях). У клипа с варпом границы цикла (`Loop/*`) и
  фейды — в долях клипа, у клипа без варпа — в секундах файла.
- Варп-маркеры — пары «секунда файла ↔ доля клипа»; между ними линейно, за краями — по
  крайнему отрезку. Последний маркер Ableton ставит сам, он продолжает наклон.
- Первая точка любой автоматизации стоит во времени `-63072000` — значение до начала.
  Кривизна записана в точке, с которой отрезок начинается (`CurveControl*` — опорные
  точки Безье в долях отрезка).
- Автоматизация привязана к цели по номеру (`PointeeId` ↔ `AutomationTarget Id`).
- Огибающая контроллера в MIDI-клипе указывает на `MidiControllers/ControllerTargets.N`
  дорожки: `N = 0` — pitch bend (−8192…8191), `1` — давление канала, дальше — контроллер
  `N − 2` (так `ControllerTargets.66` — педаль, CC 64).
- Громкость — линейное усиление; `0.0003162` (−70 дБ) значит «закрыто».
- Параметр плагина записан в диапазоне `LastUserRange`, а не 0..1; значение `0.1234567687`
  — заглушка «неизвестно».
- Состояние VST3 — `ProcessorState` и `ControllerState`; AU — plist `ClassInfo`; VST2 — чанк.
- Размер записан одним числом: `числитель − 1 + 99 × степень двойки знаменателя` (201 — 4/4).
- Путь к сэмплу надёжнее брать относительный (`RelativePath` при `RelativePathType` 3):
  проект могли перенести на другую машину.

## Формат REAPER: что выяснено вживую (REAPER 7.81)

- **Состояние VST3** REAPER принимает через `TrackFX_SetNamedConfigParm(…, 'vst_chunk', base64)`.
  Раскладка: `длина, 1, состояние процессора, длина, 0, состояние контроллера` (длины —
  uint32). Это ровно то, что хранит Ableton. Проверено на UADx 175-B, Pro-Q 4, Hammer Mk2:
  параметры после загрузки совпали со значениями из `.als`.
- **Состояние AU** через `vst_chunk` не читается и не пишется. Оно лежит в чанке трека:
  `версия (1001), 0, число входов, по 8 байт на вход, число выходов, по 8 байт на выход,
  длина plist, plist, 10 байт хвоста`. Меняется только plist и его длина
  (`import.lua: au_with_state`). Проверено на Pro-Q 4, UADx API 2500, MHB Green.
- Имя AU в REAPER — «Производитель: Имя», оба есть в `.als`. У Waves имена другие — такие
  ищутся по кодам компонента в `reaper-auplugins*-bc.ini`.
- VST3 сопоставляется по GUID (`Uid/Fields.0–3` в `.als` ↔ `{…}` в `reaper-vstplugins*.ini`),
  VST2 — по числовому идентификатору.
- **ARA-плагины** (Vovious, Melodyne) REAPER грузит через ARA: состояние из Ableton к ним
  не применяется, а второй такой плагин на дорожке он не вставляет и показывает модальное
  окно. Поэтому они не ставятся вовсе; признак — строка `ARA Main Factory Class` в файле VST3.
- Цепочка мастера в файле проекта — блок `<MASTERFXLIST`, содержимое то же, что у `<FXCHAIN`;
  огибающие мастера — `<MASTERVOLENV2`, `<MASTERPANENV2`.
- Огибающая панорамы перевёрнута: `−1` — вправо. Огибающая mute: `1` — звучит, `0` — заглушено.
- С `VOLTYPE 1` огибающая громкости в файле хранит усиление, а не шкалу фейдера.
- Цвет на macOS: `0x1000000 | R | G << 8 | B << 16`.
- Относительные пути с `..` REAPER открывает; `.mp4` и `.m4a` — источник `VIDEO`.
- Точки темпа в файле заданы временем. Ступени вместо плавных переходов дают полное
  совпадение расчёта с картой REAPER: на проекте с 33 сменами темпа расхождение 0,000 мс.
- Stretch-маркеры пишутся строкой `SM позиция источник + …`; при `SOFFS 0` и скорости 1
  позиция — секунды от начала айтема.

## Не проверено

- Звук клипов с варпом на слух: позиции маркеров сверены расчётом, сравнения с рендером
  Ableton не было.
- Единицы фейдов у клипов с варпом (доли) выведены из данных: четыре клипа с фейдом
  `0.006` при 90 уд/мин — это стандартные 4 мс.
- Закон панорамы — по документации Ableton, без измерения.
- Проекты Live 11 и старше: в Live 10 пути к файлам записаны иначе.
- AU-плагины с ARA не распознаются (признак ищется только в VST3).
- VST2 без поддержки чанков: состояние хранится списком параметров и не переносится.
